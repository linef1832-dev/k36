# ตัวดักฟังกลุ่มเช็คอิน (tg-listener)

ฟังข้อความของบอทเช็คอินในกลุ่ม Telegram แล้วเขียนลงตาราง `break_punches` ของ Supabase
หน้าเว็บ **ตรวจเวลาลุกจากที่นั่ง** อ่านจากตารางนั้นแบบสด ไม่ต้องอัปไฟล์อีกต่อไป

```
กลุ่ม Telegram ──▶ tg-listener (บัญชีคุณเอง) ──▶ Supabase: break_punches ──▶ หน้าเว็บ (realtime)
```

## ทำไมต้องมีตัวนี้

เบราว์เซอร์อ่านข้อความในกลุ่ม Telegram เองไม่ได้ และ Bot API ก็ใช้ไม่ได้เพราะต้องเอาบอทเข้ากลุ่ม
ซึ่งคุณไม่ได้เป็นแอดมินกลุ่มนั้น ตัวนี้เลยใช้ **บัญชีของคุณเอง** อ่าน (คุณอยู่ในกลุ่มอยู่แล้ว)
ไม่ต้องขอสิทธิ์อะไรจากเจ้าของกลุ่ม และไม่ได้ส่งข้อความอะไรออกไปเลย อ่านอย่างเดียว

---

## ขั้นที่ 1 — สร้างตารางใน Supabase

เปิด Supabase → SQL Editor → วางไฟล์ `sql/break_punches.sql` → Run

## ขั้นที่ 2 — ขอ API key ของ Telegram

เข้า https://my.telegram.org → API development tools → สร้าง app
จดค่า **api_id** กับ **api_hash** ไว้

## ขั้นที่ 3 — ล็อกอินในเครื่องตัวเอง (ทำครั้งเดียว)

```bash
cd tg-listener
npm install
cp .env.example .env        # ใส่ TG_API_ID กับ TG_API_HASH ลงไปก่อน
npm run login               # ใส่เบอร์ → รหัสที่ส่งมาในแอป → รหัส 2 ชั้น (ถ้ามี)
```

จะได้ข้อความยาวมากออกมา นั่นคือ `TG_SESSION` เก็บไว้ให้ดี

> ⚠️ ข้อความนั้นเท่ากับรหัสผ่านบัญชี Telegram ของคุณ ห้ามส่งให้ใคร ห้าม commit ขึ้น git
> (ไฟล์ `.gitignore` กัน `.env` ไว้ให้แล้ว)

## ขั้นที่ 4 — หา id ของกลุ่ม

เอา `TG_SESSION` ใส่ใน `.env` ก่อน แล้ว

```bash
npm run chats
```

จะขึ้นรายชื่อกลุ่มทั้งหมดพร้อม id เอา id ของกลุ่มเช็คอินไปใส่ `TG_CHATS`
มีหลายกลุ่มก็ใส่ได้ คั่นด้วยจุลภาค เช่นกลุ่ม `Jun88打卡群` กับ `Jun88-ONLINE打卡群`

## ขั้นที่ 5 — ลองรันในเครื่อง

```bash
npm start
```

รอให้บอทในกลุ่มพิมพ์สักข้อความ แล้วดูว่าขึ้น `✅ ชื่อ · หมวด · เวลา` ไหม
ถ้าขึ้นแล้ว เปิดหน้าเว็บจะเห็นข้อมูลโผล่เองทันที

## ขั้นที่ 6 — ย้ายไปรันค้างบน Railway

1. New Project → Deploy from GitHub repo → เลือก repo นี้
2. Settings → **Root Directory** = `tg-listener`
3. Variables → ใส่ให้ครบ: `TG_API_ID` `TG_API_HASH` `TG_SESSION` `TG_CHATS` `SUPABASE_URL` `SUPABASE_SERVICE_KEY`
4. Deploy แล้วดู Logs ว่าขึ้น `📡 พร้อมแล้ว`

ไม่ต้องเปิดพอร์ตหรือ domain เพราะตัวนี้ไม่ใช่เว็บ เป็นโปรแกรมรันค้างเฉยๆ

---

## ค่าที่ตั้งได้

| ตัวแปร | ความหมาย |
|---|---|
| `TG_CHATS` | id กลุ่มที่จะฟัง คั่นด้วย `,` |
| `BACKFILL_MESSAGES` | ตอนเปิดโปรแกรม อ่านย้อนหลังกี่ข้อความ (`0` = ไม่ต้อง, `500` ประมาณครึ่งวัน) ใส่เลขเยอะตอนรันครั้งแรกเพื่อดึงของเก่าเข้ามา แล้วค่อยลดลงเหลือ `0` |
| `SUPABASE_SERVICE_KEY` | ต้องเป็น **service_role** เท่านั้น เพราะตาราง RLS เปิดอยู่ ห้ามเอา key นี้ไปใส่ในหน้าเว็บเด็ดขาด |

## ถ้าข้อมูลไม่ขึ้น

- ดู Logs ของ Railway ก่อนเสมอ
- ขึ้น `เข้ากลุ่ม ... ไม่ได้` → id ผิด หรือบัญชีนั้นไม่ได้อยู่ในกลุ่ม
- ขึ้น `⏭️ ข้าม: กลับที่นั่งแต่หาเวลาเริ่มไม่ได้` → เจอข้อความกลับที่นั่งที่ไม่มีบรรทัด "เวลากิจกรรมนี้" และไม่มีรอบค้างคู่กัน ปกติเกิดตอนเริ่มรันกลางวันเท่านั้น
- ถ้าเปลี่ยนรหัสผ่าน Telegram หรือกด logout อุปกรณ์ทิ้ง ต้อง `npm run login` ใหม่
- หน้าเว็บขึ้น "อ่านตาราง break_punches ไม่ได้" → ยังไม่ได้รัน SQL ในขั้นที่ 1
